# Crédito do ícone

O ícone do programa (`app.ico`) foi gerado a partir de `icon-source-128.png`,
que é o ícone `kmix` do tema **Nuvola**, criado por **David Vignoni**.

- Autor: David Vignoni (<http://www.icon-king.com>)
- Tema: Nuvola icon theme
- Licença: GNU Lesser General Public License (LGPL), versão 2.1 ou posterior
- Texto da licença: <https://www.gnu.org/licenses/old-licenses/lgpl-2.1.html>

O arquivo `app.ico` é o mesmo desenho reamostrado para os tamanhos que o Windows
usa (16, 20, 24, 32, 40, 48, 64, 96, 128 e 256 pixels), com uma leve máscara de
nitidez nos tamanhos pequenos. Nenhum traço do desenho original foi alterado.
